    Persetujuan final & regression gate

    Persetujuan dapat diusulkan, tetapi tidak pernah memublikasikan sendiri
    Belum lulus

    Tombol persetujuan membuat usulan Final lokal dengan jejak audit dan dapat dikirim melalui GitHub Issue. Final resmi baru berlaku setelah persetujuan pengelola digabung ke dist/sishu-review-status.json, cocok dengan teks dan Hanzi, serta lulus pemeriksaan rilis. Jangan menganggap penyimpanan browser sebagai penerbitan.

    Checklist berlaku per pasal dan berdasar fingerprint naskah. Jika teks berubah setelah diperiksa, konfirmasi lama dibatalkan. Data audit pada browser ini tidak otomatis tersinkron.
